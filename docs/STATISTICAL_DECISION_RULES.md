# Statistical Decision Rules

- Bulk disease genes were selected by replicated direction and false-discovery-adjusted evidence across the public bulk evidence groups.
- Single-cell localization used patient-level pseudobulk summaries to avoid cell-level pseudoreplication.
- Disease-axis deltas are diseased-minus-healthy group differences.
- Cell-type localization P values were adjusted across evaluated cell-type groups using Benjamini-Hochberg FDR.
- Patient-label permutation tests preserved patient-level structure. For the rectal B-lineage contrast, the finite 7-versus-4 label space contains 330 unique allocations; the release includes the exact finite-label permutation summary.
- Curcumin-associated gene follow-up used BH-FDR across the 22 screened curcumin-associated disease-context genes with available rectal B-lineage contrast.
- Compound mapping is descriptive and exploratory; target-count matched null results are reported to quantify target-density dependence.
